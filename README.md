# 😄 WinYourDay

**Plan your day. Track what really happened. Celebrate small wins and laugh at the rest.**

---

## What is this?

This is a **simple but honest daily productivity tool** built with Python and `ipywidgets`.

It helps you:
- 🗓 Plan your tasks with time slots  
- ⏱ Track how much you *actually* worked  
- 🚫 Prevent overlapping schedules  
- 📊 See your real progress  
- 😂 Get funny feedback based on your performance  
- 🏆 Feel like a champion when you finish early  

---

## Why this exists

Because we all:
- plan like superheroes 🦸‍♀️  
- work like normal humans 😅  

This tool closes that gap.

---

## ✨ Features

- Task planning with start/end time  
- Overlap detection  
- Status tracking  
- Actual worked time input  
- Daily completion rate  
- Funny + motivational feedback  
- Visual charts  
- PDF report export  
- Edit / delete tasks
